      * **Scopes**: ติ๊กเลือก [x] `profile`  [x] `openid`  [x] `email`

🎯 ขั้นตอนที่ 3: ตรวจสอบ Deployment Protection (แก้ปัญหาเชื่อมต่อเซิร์ฟเวอร์ไม่ได้)
================================================================================

หากเปิดหน้าเว็บแล้วขึ้นข้อความ "เกิดข้อผิดพลาดในการเชื่อมต่อเซิร์ฟเวอร์" 
เกิดจากระบบ Vercel Authentication บล็อกการทำงานของ API ให้ทำการตรวจสอบดังนี้:

3.1 ไปที่เมนู [Settings] -> เมนูด้านซ้ายเลือก [Deployment Protection]
3.2 ดูที่หัวข้อ **Vercel Authentication**:
    - หากเปิดเป็น "Standard Protection" ให้เปลี่ยนเป็น **"Disabled"** (เพื่อให้บุคคลทั่วไปเข้าใช้งานได้)
    - กดปุ่ม [Save]

🎯 ขั้นตอนที่ 4: สั่ง Redeploy บน Vercel (สำคัญมาก เพื่อให้ค่าใหม่มีผล)
================================================================================

*** สำคัญมาก: หลังเพิ่ม/แก้ไขตัวแปรใน Environment Variables ทุกครั้ง ต้องสั่ง Redeploy เสมอ ***

4.1 คลิกที่แท็บ **[Deployments]** ด้านบนของหน้าจอโปรเจกต์บน Vercel
4.2 ดูที่รายการ Deployment บนสุด (ล่าสุด) แล้วคลิกที่ปุ่ม 3 จุด **[...]** ทางขวามือ
4.3 เลือก **[Redeploy]**
4.4 กล่องข้อความจะเด้งขึ้นมา:
    - **ไม่ต้องติ๊ก** "Use existing Build Cache"
    - กดปุ่ม **[Redeploy]** สีฟ้า
4.5 รอระบบทำการ Build ประมาณ 30 - 45 วินาที จนกระทั่งสถานะขึ้นเป็นวงกลมสีเขียว (Ready)

💡 เคล็ดลับเพิ่มเติม (Tips & FAQ):
================================================================================

Q: นำลิงก์ไหนไปใส่ใน LINE Official Account (LINE OA) เพื่อให้ลูกค้ากดลงทะเบียนฟรี 30 วัน?
A: สามารถนำ **LIFF URL** เช่น `https://liff.line.me/<LIFF_ID>` หรือ `https://food.rundev.site/lineliff`
   ไปใส่ใน **Rich Menu (เมนูด้านล่างแชท)** หรือ **ข้อความทักทายเพื่อนใหม่ (Greeting Message)** ได้ทันที

Q: ถ้าแก้ไขโค้ดในโปรเจกต์แล้ว อยากอัพเดตขึ้น Vercel ต้องทำอย่างไร?
A: - หากเชื่อม GitHub ไว้: ทำการ `git add .` -> `git commit -m "update"` -> `git push` Vercel จะอัพเดตให้อัตโนมัติทันที
   - หรือสั่ง Deploy ด่วนผ่าน Vercel CLI: เปิด Terminal ในโฟลเดอร์ `food` แล้วพิมพ์ `npx vercel --prod`

Q: รูปภาพเมนูอาหารและสลิปโอนเงินจะถูกเก็บไว้ที่ไหน?
A: ระบบเป็นแบบ Hybrid Cloud:
   1. รูปภาพจะถูกบันทึกอย่างปลอดภัยลงในตาราง `uploaded_media` ของ Cloud Database (Neon PostgreSQL) อัตโนมัติ
   2. ทำให้รูปภาพไม่สูญหายแม้ Vercel Serverless Function จะรีสตาร์ทตัวเอง
